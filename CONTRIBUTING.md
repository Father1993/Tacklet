# Contributing to Tacklet

Thanks for helping improve Tacklet.

1. Keep each change small and focused.
2. Run `python3 -m unittest discover -s tests -v` before opening a pull request.
3. Test interactions manually in a GNOME Wayland session when they affect the
   tray, keyboard shortcuts, or windows.
4. Do not add credentials, user notes, generated bytecode, or local desktop
   configuration to commits.

By contributing, you agree that your contributions are licensed under the MIT
License.
